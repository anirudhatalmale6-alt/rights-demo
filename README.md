# Global Rights Directory — maquette

Répertoire filtrable d'organisations de défense des droits humains :
domaine de droit, région, type d'intervention, recherche.

Ce que la page **ne fait pas**, volontairement : aucune année de fondation,
aucun budget, aucun effectif, aucun classement. Chaque fiche renvoie au site
officiel de l'organisation — c'est là que tout se vérifie.

La liste complète est dans le HTML servi ; le script filtre ce qui existe
déjà, il ne le fabrique pas. Sans JavaScript la page reste entière et
indexable, ce qui est tout l'intérêt d'un répertoire.

Nom de marque provisoire.
